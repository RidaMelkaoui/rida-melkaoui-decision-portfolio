# Rida Melkaoui — Decision Systems Portfolio

A professional profile for an Industrial Engineer working across data analytics, business intelligence and applied AI.

The portfolio is organized around three verified decision systems:

1. **Demand / Order** — demand forecasting translated into a replenishment policy and exception queue.
2. **Route / Control** — driver-aware route sequence learning and constrained dispatch optimization.
3. **Agent / Proof** — repeated-trial AI-agent reliability, failure diagnostics and release gating.

Each project has its own reproducible local Git repository under `projects/`, including public-data acquisition, quality controls, tested analytics, an executed notebook, an interactive dashboard, browser QA and explicit portfolio claim boundaries.

## Run the portfolio

```powershell
pnpm install
pnpm build
pnpm dev
```

The production bundle includes static builds of all three project labs under `public/labs`.

## Final deliverables

- Portfolio source and production build.
- ATS one-page resume.
- Branded one-page resume.
- Three flagship project repositories.
- Publishing handoff and verification manifest in `deliverables/final-profile`.

## Privacy boundary

The public profile describes SQE responsibilities, systems and decision value without naming confidential suppliers, customers, parts or internal projects. Project evidence uses public benchmark data or approved non-confidential claims.
